## Overview

Recursive Analysis is a research-driven storytelling app that turns complex ideas into a clean, interactive presentation flow. It is designed to help explain recursive and analytical concepts through layered sections, visual composition, and seamless navigation across slides.

### Highlights

- Modern React + TypeScript architecture
- Vite-powered fast development workflow
- Tailwind-based design system and styling
- Dynamic presentation-like slide experience
- Research-oriented layout for technical storytelling
- Responsive and visually clean presentation UI

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- GSAP
- D3 Hierarchy
- Lenis
- Lucide React

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local URL shown in the terminal in your browser.

### Production build

```bash
npm run build
```

This generates the production bundle in the `dist/` directory.

### Preview production build

```bash
npm run preview
```

## Available Scripts

```bash
npm run dev      # start the local Vite dev server
npm run build    # create production build
npm run preview  # preview the production build locally
npm run typecheck # run TypeScript checks
npm run lint     # run ESLint checks
```
